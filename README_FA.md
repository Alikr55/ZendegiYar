# زندگی‌یار V8 — Android مستقل و آفلاین

نسخه V8 برای انتشار عمومی آماده‌سازی شده و هسته برنامه داخل APK اجرا می‌شود؛ بنابراین برای اجرای خود برنامه به Netlify، اینترنت یا VPN نیاز ندارد.

## امکانات اصلی
- داشبورد فارسی و طراحی مدرن
- تقویم شمسی
- کارها و برنامه‌ریزی
- یادآوری با اعلان بومی Android
- تکرار روزانه و هفتگی یادآوری‌ها
- اهداف و مراحل هدف
- یادداشت‌ها
- مدیریت درآمد و هزینه با نمایش تومان و جداکننده هزارگان
- جست‌وجوی سراسری
- حالت روشن و تاریک
- PIN چهاررقمی
- پشتیبان‌گیری و بازیابی
- کنترل‌های تاریخ، ساعت، مبلغ و انتخاب‌ها به‌صورت داخل‌برنامه‌ای، بدون کنترل‌های خام مرورگر

## بهینه‌سازی V8
- زمان‌بندی یادآوری‌ها با AlarmManager اندروید
- بازیابی یادآوری‌ها پس از راه‌اندازی مجدد گوشی
- همگام‌سازی یادآوری‌ها هنگام افزودن، حذف، بازیابی نسخه پشتیبان و پاک‌سازی اطلاعات
- مقاوم‌سازی داده‌های localStorage در برابر اطلاعات ناقص یا خراب
- سخت‌گیری بیشتر WebView در دسترسی‌های فایل و محتوای ناامن
- آیکون اختصاصی اعلان برای نمایش بهتر در نوار اعلان

## ساخت نسخه تست
در Android Studio پروژه را باز کنید و:
Build → Build APK(s)

## ساخت نسخه انتشار مایکت
برای انتشار نهایی:
Build → Generate Signed Bundle / APK

برای مایکت بهتر است AAB یا APK امضاشده با keystore شخصی پروژه تولید شود. keystore را خصوصی نگه دارید و از آن نسخه پشتیبان امن تهیه کنید.

## نکته تست
من ساختار پروژه، Syntax جاوااسکریپت، تبدیل تاریخ شمسی و یکپارچگی فایل‌ها را بررسی کرده‌ام. در محیط فعلی Android SDK/Gradle اجرایی در دسترس نیست، بنابراین ادعا نمی‌کنم که APK را داخل همین محیط روی شبیه‌ساز یا گوشی اجرا کرده‌ام. تست نهایی نصب و اعلان روی یک گوشی واقعی باید در Android Studio انجام شود.
